Syntax overview

This page provides a concise reference for Aven's syntax and small examples to get started.

example.av
import AlKhwarzmi

start {
    name = "Aven"
    x = 10

    if x > 5 {
        write("Welcome to " + name)
    }
}

// functions
fn greet(name) {
    write("Hello, " + name)
}

Primitives

  • Numbers: 123, 3.14
  • Strings: "text"
  • Booleans: true, false

Control flow

if, else, for, while (examples above)
