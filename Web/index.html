THE LANGUAGE

Small syntax.
Serious ambitions.

Aspen is intended to be approachable on day one and powerful enough to grow with the developer. Its syntax is deliberately compact rather than packed with unnecessary ceremony.

example.apf
import AlKhwarzmi

start {
    name = "Aspen"
    x = 10

    if x > 5 {
        write("Welcome to " + name)
    }
}
