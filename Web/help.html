Getting started

Quick steps to try Aven locally and how to contribute.

Run locally

$ git clone https://github.com/Muhammad-Raller/Aven.git
$ cd Aven
$ make build
$ ./bin/aven --help

Where to ask for help

  • Open an issue on GitHub for bugs or feature requests.
  • Contact: info@raller.pro

Contributing

We welcome contributions. Fork the repo, make changes, and open a pull request. See CONTRIBUTING.md (if present) for details.

FAQ

Is Aven production-ready?

Not yet — the roadmap targets 1.0 for production stability. See the Roadmap on the home page for milestones.

How can I help?

Report issues, contribute to the standard library, or help with compiler tooling and docs.
