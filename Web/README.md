# Aspen Website

Official static landing page for Aspen 0.5.0 and Raller Projects.

## Deploying on GitHub Pages

1. Put these files in the repository used for the Aspen website.
2. Push to GitHub.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`.
5. For `aspen.raller.pro`, add the custom domain in the Pages settings.

The site is plain HTML/CSS/JS, so it needs no build step.
