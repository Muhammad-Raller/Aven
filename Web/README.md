Aven website sources and notes.

This folder contains a small, static site for the Aven language. Files:
- index.html — main site, brand updated to "Aven" and layout refreshed.
- style.css — updated, responsive styles with a modern look.
- script.js — smooth scroll + simple reveal animation.
- syntax.html — syntax reference and examples.
- help.html — getting started, FAQ, and contribution guidance.

If you'd like a more advanced build (SSG, Tailwind, or a React/Vue frontend) I can scaffold that on a feature branch.
